# Roadmap

## 0.x — Foundation y habilitación

- repo reproducible;
- Invoice mínimo;
- UBL/CUFE/firma/validación;
- integración habilitación DIAN;
- OpenAPI v1 inicial;
- documentación de onboarding.

## 0.x — Operación base

- notas crédito/débito;
- webhooks;
- multiempresa;
- object storage;
- representación gráfica;
- observabilidad.

## 1.0

Criterios tentativos:

- contrato API declarado estable;
- flujo de factura y notas probado en producción por varios usuarios independientes;
- upgrade/migration policy;
- security review;
- documentación operativa y disaster recovery;
- governance con al menos dos maintainers activos.

## Después de 1.0

Extensiones del Sistema de Facturación Electrónica priorizadas por comunidad.
