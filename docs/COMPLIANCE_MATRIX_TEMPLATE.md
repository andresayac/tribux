# Plantilla de matriz de compliance

Crear una matriz por versión/documento, por ejemplo `docs/compliance/fev-1.9.md`.

| Requirement ID | Fuente oficial | Sección/página | Regla resumida | Código | Fixture | Test | Estado |
|---|---|---|---|---|---|---|---|
| FEV19-XXX | URL/hash | ... | ... | path | fixture | test | research |

Estados permitidos sugeridos:

- `research`
- `specified`
- `implemented`
- `locally_validated`
- `habilitation_verified`
- `production_observed`

`production_observed` no significa certificación universal; solo evidencia controlada y documentada.
