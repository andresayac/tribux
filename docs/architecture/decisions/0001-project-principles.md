# ADR 0001 — Open source y self-hosted primero

**Estado:** Accepted (seed)

## Decisión

El despliegue self-hosted será el camino de referencia. El proyecto no requerirá una API central operada por los maintainers.

## Consecuencias

- credenciales y certificados permanecen bajo control del usuario;
- Docker/documentación de operación son parte del producto;
- cualquier servicio administrado futuro será opcional y no podrá convertirse en dependencia del core.
